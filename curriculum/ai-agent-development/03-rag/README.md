# 实训 03：构建带来源引用的课程知识库问答

> 本实训先实现可解释的关键词检索基线，帮助学生理解“检索—组织证据—回答—引用来源”。它不是向量检索，也不应被宣传为完整生产级 RAG。

## 学习目标

- 区分模型生成与外部知识检索
- 为文档建立标题、内容、关键词和来源
- 根据问题检索相关资料片段
- 在回答中展示证据来源
- 在没有匹配证据时明确拒答，而不是编造
- 通过测试检查命中、引用和无结果场景

## 运行

仅使用 Python 标准库，无需 API Key。

    python curriculum/ai-agent-development/03-rag/rag_demo.py

运行测试：

    python -m unittest discover -s curriculum/ai-agent-development/03-rag -p "test_*.py" -v

## 当前实现的边界

本例使用手工关键词与简单分数检索，目的是展示最小闭环：

问题 → 检索候选文档 → 选取证据 → 输出答案与来源。

它不包含 embedding、向量数据库或 LLM 生成。后续扩展时可替换检索器为向量检索，再增加生成模型，但应保留来源、拒答和回归测试。

## 学生任务

### 基础

1. 运行示例并查看引用来源。
2. 在 documents 中增加一条原创课程资料。
3. 为新资料增加关键词，并补充测试。
4. 输入无关问题，观察系统是否拒答。

### 提高

1. 实现 top-k 参数。
2. 增加最低检索分数阈值。
3. 记录每个候选文档的匹配分数。
4. 分析关键词检索容易漏掉哪些同义表达。

### 挑战

设计一个小型检索评测集，至少包含应命中、应拒答、相似主题干扰三类问题。比较不同关键词和阈值下的召回与误命中。

## 验收标准

- 命中时返回来源标题
- 无匹配资料时明确说明未找到
- 不把检索不到的内容伪装成有来源的答案
- 测试覆盖命中、无结果和来源标记
- README 说明当前检索方法的局限
