# AI 智能体开发：课程大纲与教学设计

> 状态：课程设计初稿，尚未经过真实课堂验证。课时与评价方式应根据学校专业方案和学生基础调整。

## 1. 课程定位

面向具备基础 Python 编程能力的高职计算机类学生，培养其使用大模型构建、测试、调试和部署 AI 应用的能力。课程强调工程实践，不要求学生从零训练基础大模型。

## 2. 建议先修知识

- Python：函数、列表与字典、模块、异常处理
- HTTP 与 JSON 基础
- 基本 Git 和命令行操作

## 3. 学习成果

完成课程后，学生能够：

1. 区分普通 LLM 调用、确定性工作流与工具型智能体。
2. 调用模型 API 并验证结构化输出。
3. 定义工具的用途、参数和返回格式。
4. 实现工具白名单、参数验证、错误处理和最大执行步数。
5. 构建基于公开文档的简单 RAG 问答并显示来源。
6. 设计任务测试集，分析成功率、工具选择错误和失败原因。
7. 说明提示注入、隐私、密钥管理和人工确认的基本风险。
8. 交付可复现的小型 AI 应用和技术文档。

## 4. 建议课时：32 学时

| 模块 | 学时 | 关键知识 | 实训成果 |
|---|---:|---|---|
| 大模型应用基础 | 3 | 请求/响应、消息结构、Token、成本与异常 | 调用模型并输出结果 |
| 结构化输出 | 3 | JSON、Schema、校验与重试 | 经过校验的数据对象 |
| 工具调用 | 5 | 工具定义、参数验证、注册与返回 | 计算器 + 课程 FAQ |
| 智能体循环与工作流 | 4 | 状态、路由、步数限制、终止条件 | 多步骤任务执行器 |
| RAG 知识库 | 5 | 文档切分、检索、引用与拒答 | 带来源的课程问答 |
| 评测与安全 | 4 | 任务成功率、回归集、提示注入、最小权限 | 小型评测报告 |
| 部署与综合项目 | 8 | API、配置、日志、测试、文档与演示 | 课程助教智能体 |

高职课程通常强调实践性教学；实际学时与实践比例应以学校适用的专业标准和人才培养方案为准。

## 5. 单元设计

### 单元 01：智能体是什么

- LLM 调用、固定工作流、工具型智能体的区别
- 智能体的组成：模型、指令、工具、状态、执行循环、评价
- 何时不需要智能体：简单规则和确定性流程优先
- 实训：运行本地工具调用示例

### 单元 02：大模型 API 与结构化输出

- API Key 与环境变量
- 消息、上下文、超时与重试
- JSON 输出、字段验证和异常处理
- 实训：将用户请求转换为经过校验的任务对象

### 单元 03：工具调用与参数校验

- 工具名称、描述、参数 schema 和返回格式
- 工具白名单与权限边界
- 参数验证、超时、失败和重试
- 实训：注册计算器、课程 FAQ 和统计工具

### 单元 04：智能体执行循环

- 任务状态、工具选择、结果回传
- 最大步数、循环检测、终止条件
- 只读工具与有副作用工具的区别
- 实训：构建多步骤工作流

### 单元 05：RAG 知识库问答

- 文档解析、清洗、切分和元数据
- 关键词检索与向量检索的基本思想
- 回答引用、无依据时拒答、检索质量检查
- 实训：用公开课程文档构建带来源的 FAQ 助手

### 单元 06：智能体评测与安全

- 任务成功率、工具选择正确率、参数正确率
- 固定回归集与失败分类
- 提示注入、工具越权、隐私与密钥泄露
- 人工确认、审计日志和最小权限
- 实训：对比两个版本并分析失败案例

### 单元 07：工作流、多智能体与协议

- 状态机、条件分支和人工审批节点
- 多智能体的适用条件与额外成本
- MCP 的工具服务与客户端概念
- 实训：先实现单智能体，再判断是否需要拆分角色

### 单元 08：部署与项目验收

- 配置管理、日志、测试、依赖管理
- Web API 或命令行接口
- 成本、延迟、失败恢复与部署说明
- 实训：提交可复现项目、测试报告和演示视频

## 6. 第一个实训：本地工具调用

入口：[01-tool-calling](01-tool-calling/README.md)。

该实训不需要 API Key，不连接外部服务。使用确定性路由器演示工具注册、参数验证、执行结果与终止条件。

**说明：这是一份帮助初学者理解控制流的教学脚手架，不是具有自主推理能力的 LLM 智能体。**后续单元再将路由器替换为真实模型的工具调用接口，并保留权限与执行限制。

## 7. 综合项目：课程助教智能体

建议支持课程资料查询、简单计算、练习题草案生成、回答依据展示、任务日志和固定评测。

不建议一开始实现自动修改成绩、未经确认发送通知、执行任意 shell 命令，或把无来源的模型输出当作课程政策事实。

## 8. 项目验收量规（建议）

| 维度 | 权重 | 验收证据 |
|---|---:|---|
| 功能正确性 | 25% | 预先定义的任务与测试通过 |
| 工具设计与参数校验 | 20% | 工具 schema 清楚，非法输入可控失败 |
| 错误处理与终止控制 | 15% | 错误与步数上限有测试 |
| 评测与问题分析 | 15% | 固定测试集、指标与失败案例 |
| 安全与隐私 | 15% | 无硬编码密钥，权限清晰，有人工确认边界 |
| 文档与演示 | 10% | 安装、运行、测试和演示说明完整 |

该量规是建议稿，不是学校官方评分标准。
