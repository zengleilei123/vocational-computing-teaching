## 基础题

### 练习 1：自我介绍

读取姓名和专业，输出：

```text
你好，我叫小林，专业是计算机应用技术。
```

要求：
- 使用两个变量保存输入。
- 输入前给出清晰提示。
- 输出使用 f-string。

### 练习 2：矩形面积

读取长和宽，输出矩形面积，保留两位小数。

要求：
- 将输入转换为浮点数。
- 检查长和宽必须大于 0。
- 输出面积及单位。

### 练习 3：成绩平均分

读取三门成绩，计算平均分并保留一位小数。

要求：
- 成绩必须是 0 到 100 的数字。
- 解释为什么不能直接把 `input()` 的返回值相加。

## 提高题

### 练习 4：消费账单

输入商品名称、单价和数量，计算总价。

要求：
- 单价必须大于等于 0。
- 数量必须是正整数。
- 输出格式如：`笔记本：3 件，共 15.00 元`。

### 练习 5：温度转换

输入摄氏温度，转换为华氏温度。

公式：`F = C * 9 / 5 + 32`。

要求：
- 输出保留一位小数。
- 给公式中的变量添加注释。

## 调试题

下面代码为什么不能正确计算平均分？请修复并解释。

score1 = input("第一门成绩：")
