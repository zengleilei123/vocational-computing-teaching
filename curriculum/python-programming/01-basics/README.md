## 三、核心概念

### 1. 程序的基本流程

输入数据 → 程序处理 → 输出结果。

变量用于给数据命名，表达式用于计算，函数调用用于完成具体操作。

### 2. 类型转换

`input()` 返回字符串。若输入代表数字，需要显式转换：

```python
score = float(input("请输入成绩："))
```

直接对字符串和数字执行不支持的运算，可能产生类型错误。教学时应强调：先明确数据类型，再选择合适的操作。

### 3. 格式化输出

推荐使用 f-string：

```python
name = "小林"
score = 88.5
print(f"{name} 的成绩是 {score:.1f} 分")
```

## 八、常见错误

1. 忘记把 `input()` 的结果转换为数字。
2. 将变量名写错或大小写不一致。
3. 使用全角符号替代 Python 语法中的半角符号。
4. 将平均分计算写成整数除法以外的错误表达式。
5. 没有检查输入数量或输入格式。
