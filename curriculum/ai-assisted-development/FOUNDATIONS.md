# 算法够用、开发扎实：课程内容取舍

> 这是项目强化单元建议，不是降低学生发展上限，也不替代学校人才培养方案。目标岗位、继续升学或竞赛方向不同，应另加深度模块。

## 1. 必学：能解释并写出小规模实现

| 知识 | 开发中的问题 | 达标证据 | 建议回顾学时 |
|---|---|---|---:|
| 列表、字典、集合与去重计数 | 报名去重、地图按 ID 查询、报修类别统计 | 说明相同姓名不等于同一用户，选择稳定业务键 | 2 |
| 排序、筛选、Top-k | 任务优先级、最近作品、前三个检索结果 | 会用库函数和多字段 key；空值、同分有明确规则 | 2 |
| 栈、队列 | 地图撤销、任务排队 | 两次编辑可以逐次撤销；先进先出不被误写成后进先出 | 2 |
| 区间与边界判断 | 预约冲突、时间范围筛选 | 区分重叠、包含、相邻、零长度区间 | 2 |
| 复杂度直觉、规模与正确性 | 样本变大后卡顿，循环不结束 | 区分 O(n)、O(n log n)、O(n²)，构造边界测试 | 2 |
| 状态转换和业务不变量 | 待确认/已确认、正在执行/可编辑 | 画出合法状态转换，测试重复操作和非法跳转 | 2 |
| 合计 | | | 12 |

状态机属于程序设计与工程基础，不强行称为某个排序算法。12 学时是已学过程序设计后的集中回顾和应用，不是从零完成一整门数据结构课。

具体练法：报名输入 `A,A,B`，要求第一次保留、第二次不新增；Top-k 输入数量不足 k 时返回实际数量；撤销记录必须保存旧状态而不是同一个可变对象的引用；预约采用半开区间时 `[09:00,10:00)` 与 `[10:00,11:00)` 不冲突。正确性先于优化。

## 2. 按项目选学：会用、会比较，不要求人人手写所有底层

- 二分查找：先验证数据有序；说明查找位置和插入元素不是同一成本。Python bisect 文档明确 O(log n) 查找不能掩盖列表插入的 O(n) 成本。[S6](SOURCES.md)
- 树、遍历、图：文件夹/菜单层级、课程先修关系。沿用 CoursePilot 的拓扑规划，检查环和缺失节点。
- BFS、Dijkstra：沿用机器人地图。BFS 适合等步长最少步数；Dijkstra 针对非负权成本，不用它处理负权场景。
- 文本与图像分类入门：沿用工单朴素贝叶斯和符号 k-NN，讲数据划分、标签、阈值和错例。不要再为了“显得 AI”堆十种模型。
- 缓存、分页、重试与限流：作为工程模式讲清失效、重复请求和上限；不把防抖当作服务端权限或并发控制。

## 3. 不列为本轮统一必修

高难动态规划、竞赛数论、复杂图论、手写红黑树、手写所有排序算法、从零训练大型基础模型。不代表它们没有价值，而是当前项目的优先级较低；升学、竞赛、算法岗与兴趣小组保留拓展路径。不要把取消部分刷题误解为取消数学、网络、操作系统或专业基础。

## 4. 36 学时开发桥接主线

| 模块 | 学时 | 要能做什么 | 复用项目 |
|---|---:|---|---|
| 环境与运行 | 4 | 终端、路径、依赖、端口、读取报错 | 启动机器人挑战场 |
| 网页与交互 | 8 | HTML/CSS/JS、表单、DOM、状态、移动端与键盘操作 | 地图名称、编辑/运行状态、错误提示 |
| HTTP 与后端 | 6 | JSON、请求响应、状态码、路由、输入校验 | 追踪 `/api/solve`，解释 400/404/415 |
| 数据与持久化 | 8 | SQL 增删改查、唯一约束、事务、参数化查询、导入导出 | 设备预约；把内存/浏览器存储与数据库区分 |
| 调试、安全与交付 | 6 | DevTools、日志、环境变量、测试、Git diff/分支/PR/回退 | 一次失败修复和可复现交付 |
| AI 应用接口入门 | 4 | 模型超时、结构化结果、费用、假客户端与失败回退 | 原有 LLM 工具调用实训 |
| 合计 | 36 | | |

以上是一个桥接单元，不声称 36 学时即可成为全栈工程师。零基础应使用完整学期安排。

先维持仓库已有的 Python + HTML/CSS/JavaScript + SQLite；基础稳后再按学校教学需要选一个前端框架和一个后端框架。不要同时新增 React、Vue、Java、Python、多种数据库和多个 Agent 框架。MDN 的基础课程把 HTML、CSS、JavaScript、可访问性、版本控制放在同一学习路径中，可作参考。[S2](SOURCES.md)

## 5. 每个知识点都要回答四个问题

它解决什么需求？最简单实现是什么？哪种输入会失败？怎样验证改进？

“会背复杂度”但不能判断重复写入，不达标；“能让 AI 写出页面”但不知道数据存在哪里，也不达标。程序员应能解释关键数据流，验证并修改主要业务逻辑；不要求背诵每一段框架样板代码。
