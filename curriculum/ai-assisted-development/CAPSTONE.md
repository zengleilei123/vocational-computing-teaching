# 综合作业：把机器人演示改成“我的地图作品集”

> 下列保存、导入和存档管理是 **本课学生待实现的功能**，不是本轮已交付代码。起点是仓库已有的 [机器人挑战场](../../projects/robot_playground/README.md)，它能编辑、求解、回放并导出实验，但页面临时状态不会自动持久化。

## 用户故事与边界

“我设计了一张有意思的校园地图，希望给它命名，刷新后继续修改；导出文件后，同学能在自己的浏览器里导入并测试。”

基础版只在当前浏览器本地存储地图，不收姓名学号，不做账号、云同步、远程执行或公开排行榜。地图不是分类训练样本；不要顺手持久化整个页面状态。地图对照仍然只比较同一张地图的结果。

## 三个增量版本

| 版本 | 新增需求 | 开发知识 | 验收重点 |
|---|---|---|---|
| V1 本地存档 | 命名、保存、列表、加载、删除前确认 | JS 对象、状态、表单、本地存储 | 刷新后可恢复；删除须显式确认 |
| V2 作品交换 | JSON 导出/导入、版本字段、结构校验 | 文件读取、JSON、接口契约、错误恢复 | 坏文件不改变当前地图和已有存档 |
| V3 工程升级（选做） | SQLite 存储、HTTP CRUD、迁移与备份 | 数据库、事务、API、配置、持久化 | 服务重启后数据仍在，重复写入有约定 |

V1/V2 是 24 学时主任务；V3 结合前面的 36 学时开发桥接实施，不要求基础薄弱学生同时完成。现有本机 HTTP 服务不是生产服务器，完成 V3 也不等于可以直接公网部署。

## 建议的数据契约（本课新增设计）

```json
{
  "version": 1,
  "name": "我的配送地图",
  "grid": ["S..", ".#.", "..G"]
}
```

地图几何约束复用现有 engine 的约定：矩形、最多 20×20、唯一 S/G、只含 `S G # . 2–9`。首先读已有校验实现，再复用或等价校验，不发明与后端矛盾的新规则。

名称去除首尾空白后 1–40 个 Unicode 码点；中英文均可，代码需明确 JS 的 UTF-16 长度与 Unicode 码点差异。`version` 只能为整数 1，拒绝布尔值和字符串版本；顶层字段限定为 version/name/grid。导入 UTF-8 JSON 文件最多 16 KiB，此限制是课程设计，不能与服务器已有 64 KiB 请求限制混为一谈。

同名保存不静默覆盖：要求学生选择改名或显式覆盖；覆盖只改变选中地图。拒绝损坏数据时保留原页面与存档。单人浏览器版不保证多个标签页并发编辑一致性，应在已知限制中说明。

本地存储不是保险箱，不存密钥和真实个人信息。名称展示使用文本插入而不是 HTML 拼接。浏览器本地存储的 API 与异常处理参考 [S8](SOURCES.md)。

## 教师保留的独立验收用例

| ID | 输入/操作 | 必须满足的结果 |
|---|---|---|
| A01 | 保存合法地图，刷新，再加载 | 名称与网格一致 |
| A02 | 空白名称、41 个码点的名称 | 拒绝，已有记录不变 |
| A03 | 相同名称第二次保存 | 不静默覆盖，有明确选择 |
| A04 | 取消删除 | 记录仍在 |
| A05 | 非法 JSON、未知 version、顶层数组 | 可读错误，不破坏当前状态 |
| A06 | 缺 S/G、两个 S、不等宽行、21 行 | 导入失败，不出现半条记录 |
| A07 | 超过 16 KiB 文件 | 在解析前拒绝 |
| A08 | 名称含 `<b>地图</b>` | 作为普通文本呈现，不执行 HTML |
| A09 | 存储写入抛出异常/历史记录损坏 | 提示失败或忽略坏记录，不崩溃、不伪报成功 |
| A10 | 用键盘完成保存、加载和确认 | 控件有标签，焦点可见 |
| A11 | 旧求解、回放、分类测试 | 保持通过，不改预测后显式确认规则 |
| A12 | 导出 A，再在空浏览器导入 A | 按契约恢复；不声称自动云同步 |

检查学生测试是否真正观察这些结果，而不是只调用函数却没有断言。学生先自查，再由同学或教师独立执行至少 3 个反例。

## 自主选题不改变质量要求

允许将功能主题改成“社团装备预约小站”或“个人任务看板”，但必须保留：一个明确用户问题、一个数据存储点、一次失败恢复、一组独立验收、一次版本回退和个人讲解。不因为用了更大模型或更多框架加分。

## 本课不接受的捷径

不通过删旧测试、把所有异常变成成功、只隐藏按钮、用 AI 生成假运行截图、要求关闭安全限制来完成验收。不自动上传课堂数据、不实际付款或派单。需要这些能力的项目应另行设计权限、审核和部署流程。
