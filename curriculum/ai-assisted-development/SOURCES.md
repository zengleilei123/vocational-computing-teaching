# 官方资料与设计依据

核对日期：2026-10-28。来源仅支持相应事实或功能说明；本课程的 72/24 学时、评分、选题及安全任务约束是原创建议，不是官方要求或工具厂商背书。不同 AI 工具功能与许可可能变化，开课前重新核对。

| 编号 | 来源 | 本课程如何使用 |
|---|---|---|
| S1 | [教育部：2025 计算机应用技术专业教学标准](https://hudong.moe.gov.cn/s78/A07/zcs_ztzl/2017_zt06/17zt06_bznr/bznr_zyjyzyjxbz/gdzyjy_zk/zk_dzyxxdl/dzxxdl_jsjl/202502/P020250207533801162064.pdf) | 第 3–4 页包含数据结构与算法分析、数据库、前端及项目化教学；不能推出算法应被取消 |
| S2 | [MDN Core learning modules](https://developer.mozilla.org/en-US/docs/Learn_web_development/Core) | HTML、CSS、JS、可访问性、设计和版本控制的基础开发路径 |
| S3 | [GitHub：Responsible use of Copilot Chat](https://docs.github.com/copilot/responsible-use/chat-in-github) | 使用者须审查和测试生成代码；AI 不替代人的判断 |
| S4 | [Claude Code best practices](https://code.claude.com/docs/en/best-practices) | 明确上下文和验收；区分提示约定与权限/测试/CI 等执行约束 |
| S5 | [Cursor Agent overview](https://cursor.com/docs/agent/overview) | 工具、代码审查与 checkpoint；checkpoint 不代替 Git |
| S6 | [Python bisect](https://docs.python.org/3/library/bisect.html) | 有序序列查找与插入复杂度的区别 |
| S7 | [Python Data Structures](https://docs.python.org/3/tutorial/datastructures.html) / [Sorting HOWTO](https://docs.python.org/3/howto/sorting.html) | 列表、集合、字典、栈/队列与按 key 排序；优先正确使用库 |
| S8 | [MDN localStorage](https://developer.mozilla.org/en-US/docs/Web/API/Window/localStorage) | 浏览器本地存储与可能的访问异常；不把它当账号云存储或秘密保险箱 |

| S10 | [Git revert](https://git-scm.com/docs/git-revert) | 用反向提交保留已提交变更历史，不混淆代码与数据恢复 |

没有复制付费题库、教材或厂商整段文档。工具提示、任务与验收均为课程设计示例。无需为了完成课程购买所有列出的工具。
