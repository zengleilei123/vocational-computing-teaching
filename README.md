# Vocational Computing Teaching

面向高职计算机类专业的课程设计、编程教学、算法训练与工程实训资源库。

本仓库以“能讲清、能运行、能练习、能评价”为原则，持续沉淀可复用的教学材料与小型工程项目。它不是某所学校的官方课程，也不替代具体院校的专业人才培养方案。

## 建设目标

- 课程设计：将课程目标、知识依赖、学时安排和考核方式写清楚。
- 编程教学：提供循序渐进的讲解、示例代码、练习与测试。
- 算法训练：强调问题建模、正确性、复杂度、边界情况和教学表达，而非只收集题解。
- 工程实训：让学习者完成从需求、实现、测试到文档和部署的完整流程。
- AI 应用：在编程、数据库和软件工程基础上，逐步加入数据分析与 AI 应用开发。

## 目标学习者

主要面向高职计算机类专业学生，也适合需要系统复习编程与工程实践的初学者。默认读者具备基本计算机操作能力，但不假设其已有扎实的编程基础。

## 内容路线

1. Python 程序设计基础
2. 数据结构与算法
3. SQL 与数据库应用
4. 文件处理与数据分析
5. 软件工程、测试、Git 与 Linux 基础
6. 综合项目与 AI 应用拓展

## 当前状态

项目处于初始建设阶段。内容会按模块逐步完善；每个模块应尽可能包含：

- 学习目标与先修知识
- 教学讲解与示例
- 学生练习和分层任务
- 测试用例与常见错误
- 参考解答和评分建议

## 如何使用

从 [课程路线图](ROADMAP.md) 开始。教师可以复用模板组织课程；学习者可以按模块完成练习。请根据自己的教学环境和学习进度调整内容。

## 质量原则

- 示例代码应可运行，并注明运行环境。
- 题目应有明确输入、输出、约束和测试。
- 参考答案应解释思路，不只给出代码。
- 课程目标应能通过练习或项目验收。
- 使用公开或自行构造的数据；不提交个人隐私、商业机密或未经授权的材料。
