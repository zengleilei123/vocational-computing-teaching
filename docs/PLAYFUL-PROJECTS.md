# 从可用项目到学生自己的作品

新入口：[校园机器人挑战场](../projects/robot_playground/README.md)。这次是有网页交互的两个项目，不是增加一组只有说明文档的题目。

| 学生体验 | 学习任务 | 已实现 |
|---|---|---|
| 亲自开机器人、改地形、交换关卡 | 二维数组、状态、图搜索、代价函数与反例 | 手动移动、地图编辑、BFS/Dijkstra、学生策略、路线回放 |
| 画自己的暗号教机器人 | 数据标注、像素特征、k-NN、留出测试、拒识 | 5×5画板、四类采样、独立测试、预测确认后移动 |

启动：`python -m projects.robot_playground.server --port 8765`，打开本机 `http://127.0.0.1:8765`。

教师使用 [四学时设计](../projects/robot_playground/TEACHING.md)，学生使用 [自选任务卡](../projects/robot_playground/CHALLENGES.md)。先体验，再解释，再修改；可选择关卡设计、算法实现或数据改进方向。最终提交实验记录，而不是只交高分截图。

这些能力可作为已有课堂验收与 CoursePilot 的人工评价证据。目前未自动同步成绩，未接入真实机器人或外部大模型；所有学习效果判断都需真实试教验证。

后续创意可以沿同一结构扩展：地图主题换为送书/救援，像素输入换为音频指令，单机器人换为多机器人避碰。后两项只是扩展任务，尚未实现；先把当前两项的学生作品和反馈收集好。
