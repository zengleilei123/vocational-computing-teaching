# 教师地图作品集参考实现计划

**Goal:** 交付隔离的 V1/V2 教师参考实现、A01—A12 独立验收及可复现故障练习，保留学生起始任务。

**Architecture:** `teacher_reference/robot_map_portfolio/` 使用单独启动入口，继承现有 Python HTTP Handler 并只读复用学生页面、样式和 app.js。教师页面额外装配作品集表单、独立 JS 数据层与适配层；学生服务的路由与文件不变。

**Tech Stack:** Python 3.10+ 标准库、原生 JavaScript、Node 内置测试、现有 Python unittest 与 Playwright 1.57.0。

**Spec:** [CAPSTONE.md](../../../curriculum/ai-assisted-development/CAPSTONE.md)，基线提交 `940ba7ee616d160e47d6e41d5473792105ac6470`。

## 全局约束与实现决定

- 学生 `projects/robot_playground/` 的源码、测试和待实现任务不作修改；教师默认端口 8766，学生仍为 8765。
- 持久化仅限 `{version,name,grid}`，一个独立 localStorage 键保存数组；不保存训练样本、预测或评分。
- 名称 trim 后 1–40 个 Unicode 码点，版本严格为整数 1，顶层仅三个契约字段。
- 地图与 engine 等价校验：行、列各 3–20，唯一 S/G，字符限定 `#.SG23456789`，无解地图合法。
- UTF-8 JSON 导入上限 16384 字节，读取和解析之前检查文件大小。
- 同名覆盖、删除均显式确认；校验和写入成功后再更新列表与地图；异常保留当前状态。
- 损坏的单条历史记录可跳过并警告；整个容器损坏则保留原始字节、阻止写入，教师文档说明备份和恢复。
- 不增加云端存储、账号、V3、构建框架；多标签页并发一致性不作保证。
- 用户已指定目标、任务书、技术栈优先级和隔离要求，按这些约束直接实现，不增加审批步骤。

## 风险与验证重点

1. 存储失败不能留下成功提示、虚假列表或被替换的当前地图。
2. 40 个 astral 字符合法，41 个不合法；文件限制计算字节而非 JS 字符长度。
3. 读文件期间阻止地图切换/求解，旧请求不得污染新地图。
4. 名称作为文本显示；键盘可保存、加载、取消/确认，弹窗焦点可见且返回发起控件。
5. 在真实浏览器来源上测试刷新持久化与跨浏览器上下文导入；缺依赖不得伪报验收通过。
