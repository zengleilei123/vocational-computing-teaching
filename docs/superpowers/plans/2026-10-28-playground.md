# 校园机器人挑战场实施记录

目标：用两项互通的可玩任务，让学生自主设计地图、策略和训练样本，而不只操作教师成品。

基线：a15543092ae353bd5cf5ff7d5b85e493302eff23，继续 PR #1。Python 标准库 + 原生 HTML/CSS/JS；不改变旧项目行为。

## 决策

- 以网格矩阵为教学对象，使用可编辑代码原生单元格，不引入游戏素材或框架依赖。
- 图搜索、k-NN、模型工具调用分开讲，不把确定性算法包装为大模型。
- 仅本机、无持久化采集、无摄像头、无公共排行榜、无自动成绩写入。
- 页面导出未评分证据，经教师复核才接回既有课程验收流程；没有自动集成。
- 本地浏览器受网络策略限制，未修改策略。分开验证真实 HTTP 与离线 DOM；CI 新增独立真实浏览器 HTTP 作业。

## 执行证据

- 测试先于新模块编写，首轮因 engine 缺失失败；实现后新增37项测试通过。
- 覆盖地图合法性、无解、非法动作、两类路径目标、k-NN拒识、训练测试完全重合、Host/Origin和请求体限制。
- Chromium离线DOM检查覆盖14类交互，桌面1440×1100与移动390×844；无页面脚本异常或横向溢出。
- 审图后移除遮挡表格的悬浮提示条；增加编辑地图时的请求互斥。
- 新功能同一次完整提交更新分支；原有所有CI检查保留。最终远端结论以对应提交的Actions结果为准。

## 未完成范围

真实课堂试教、真实机器人、多用户服务、自动验收导入、语音/视觉模型、生产部署均不在本次实现范围。
