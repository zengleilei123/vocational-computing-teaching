# 课堂实训项目包实施与验收记录

Goal: 将设备预约、报修分类、项目验收反馈组织成三个可独立上课又可接入 CoursePilot 的项目。
Architecture: 标准库离线实现；原有 Store 不改动；新模块位于 projects/classroom_practice，数据全为合成。
Tech Stack: Python 3.10+、SQLite、字符二元组多项式朴素贝叶斯、unittest。

## 边界与方案
采用三个小项目而不是继续扩大单一 RAG：设备预约承载数据库事务，报修分类承载训练与评价，成绩导入连接原有学情与计划。
不用真实学生资料，不执行学生提交代码，不实际派单，不添加网络服务或真实教务写入权限。参考解与学生任务明确分开。

## 任务
- [x] 先写并运行失败测试，覆盖预约重叠/相邻/并发/幂等，分类切分/词表隔离/指标，成绩整批校验/重放/显式确认。
- [x] booking.py：带时区时间归一化；BEGIN IMMEDIATE 内检查冲突与插入，重复请求不得更改参数。
- [x] classifier.py + tickets.csv：训练/验证/测试分组互斥；训练集学习词表与参数；固定平滑=1；无词表命中转人工；输出混淆矩阵与 macro-F1，不声称实际泛化。
- [x] assessment.py + assessments.csv：同一 evidence_id 不得重复写入；同 ID 改分拒绝；批次原子性；复用 Store 的 progress/draft，不自动批准。
- [x] app.py：三个命令在仓库根目录运行；离线验收；返回清楚 JSON，不依赖网络和密钥。
- [x] 每项目提供需求、分层学生任务、教学节奏、故障练习、评分量规及证据模板；链接官方依据。
- [ ] 本地测试和编译通过后，一次完整提交更新现有 PR 分支，再核查对应 SHA 的 CI；不直接合并 main。

## 重点复核
时区不同但表示同一时刻；同请求 ID 的数据变更；同设备的两个并发写入；测试集特征误进词表；导入到中途失败后残留成绩。
