# 数据卡与教学使用约定

## tickets.csv

由项目作者为教学独立撰写的57条中文合成报修描述，不来自真实学生、学校工单或公开数据集。三个标签：network/hardware/software。
训练36（每类12）、验证9（每类3）、测试12（每类4）。训练中同一表达家族的两个改写共享group；验证与测试使用单独group。它们仍来自同一作者，相似主题和语义近重复风险存在，分组检查不构成独立来源评测证明。

字段：id唯一；group为表达家族标识；split为train/dev/test；text为描述；label为目标类别。
先固定划分，再只用train构建词表和参数。dev用于将来比较设置，test不用于调参。当前平滑1、margin阈值1均预先固定。不能复制测试错例到训练集后仍报告原测试集为独立泛化。

当前任务为单标签闭集分类；复合故障、否定句、跨域需求属于局限。无词表命中或分数差不足时转人工，只是简单兜底，不保证检测所有域外输入。

## assessments.csv

5条合成的教师验收能力项评分，学生ID为learner_01。字段：evidence_id、student、project、topic、score。
分数用于演示数据管线，不是模型自动评分，不是实际学生成绩，不能据此推断学生能力或教学效果。

## 预约示例

合成设备camera-01、robot-01；时间固定为带时区的示例日期。没有真实库存，也没有连接设备。

## 更新数据

保持来源、标注规则、分组方式与版本记录；先运行数据校验。使用真实数据前另行取得授权、脱敏和审查。本包无个人信息采集要求。
