# 学生项目提交模板

- 项目/版本：
- 合成学习者ID/小组：
- 本人负责内容（具体到功能）：
- 数据来源与许可：
- 使用AI辅助的范围与本人验证方式：

## 1. 需求与边界
用自己的话说明谁要解决什么问题。列出必做、选做和不能做的操作。

## 2. 数据与接口
字段、类型、范围、错误处理；解释request_id/group/evidence_id中本项目使用的字段。

## 3. 关键实现
附文件路径与关键函数；解释一个设计取舍，不要求复制所有代码。

## 4. 验收记录
| 案例 | 输入 | 预期 | 实际 | 通过/失败 | 证据位置 |
|---|---|---|---|---|---|
| 正常情况 | | | | | |
| 边界情况 | | | | | |
| 应拒绝情况 | | | | | |
| 重复/恢复情况 | | | | | |

## 5. 一个失败案例
发生了什么？根因是什么？如何验证修复没有破坏其他情况？未修复也应如实说明。

## 6. 个人现场答辩
题目、修改内容、运行结果、解释；不要把小组演示当作个人独立完成证据。

## 7. 教师反馈（教师填写）
量规各项得分、下一步学习建议。未开展课堂评价时保持空白。
